## Problem statement

Wine quality assessment is traditionally performed by expert sommeliers
— a subjective, expensive, and unscalable process. This project builds
a machine learning pipeline to predict wine quality scores (3–8) from
physicochemical properties including acidity, alcohol content, and
sulphates, comparing Random Forest, Gradient Boosting, SVM, and
Logistic Regression classifiers.

*Developed during the Bharat Intern Machine Learning Virtual Internship,
10 August – 10 September 2023.*
